# Folio icon options

Open `index.html` for a responsive comparison with light/dark backgrounds, a wordmark, and actual 16/24/32 px samples. `comparison.svg` is a portable contact sheet.

| Option | File | Idea |
| --- | --- | --- |
| 01 · Folded F | `folded-f.svg` | A geometric initial with a folded paper corner. The most distinctive app identity. |
| 02 · Open Volume | `open-volume.svg` | Two sculpted pages; quiet, literary, and immediately recognizable. |
| 03 · Ink Nib | `ink-nib.svg` | A fountain pen silhouette with a cutout; emphasizes writing. |
| 04 · Story Door | `story-door.svg` | An open doorway; evokes entering a fictional world. |

All four are original SVG paths with a 64 × 64 viewBox. They contain no fonts, raster images, scripts, or external resources. Inline them to inherit `currentColor`; when used as an image, they default to black. The comparison uses color only for presentation, so any mark can use any palette.

**Selected: 01 · Folded F.** The app uses this mark in its header, SVG favicon, ICO fallback, and Apple touch icon. The original alternatives remain here for reference.
